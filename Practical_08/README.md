# Practical 08 — Campus Cup API
Express routing, request middleware, query filtering and JSON body validation.
Run: `cd server && npm install && npm start` (port 5408).
Try `GET /api/entries`, `GET /api/entries?sport=Cricket`, `GET /api/entries/1`, and `POST /api/entries` with JSON `{ "team":"Hill Lions", "sport":"Basketball", "players":5 }`. Data is in memory and resets on restart.
